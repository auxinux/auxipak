# Traductions

La langue de référence d'AuxiPak est le **français**. Ce document explique
comment ajouter la traduction anglaise de la documentation et comment
traduire l'interface Web.

## 1. Documentation

Structure prévue :

```text
docs/
  README.md, INSTALLATION.md, …     documentation de référence (français)
  en/
    README.md, INSTALLATION.md, …   traduction anglaise, mêmes noms de fichiers
```

Règles :

1. Créer `docs/en/` et y traduire les fichiers **en conservant leurs noms**,
   leur structure de titres et leurs ancres (les liens relatifs entre
   documents restent ainsi valides).
2. Ne traduire ni les commandes, ni les options, ni les noms de champs, de
   variables d'environnement, de routes ou de fichiers : ils sont identiques
   dans toutes les langues.
3. Indiquer en tête de chaque fichier traduit la révision Git du document
   français source (« Traduit depuis docs/INSTALLATION.md, révision
   `<sha>` ») pour repérer les traductions à mettre à jour.
4. En cas de divergence, le document français fait foi.
5. Ajouter un lien vers `docs/en/README.md` dans `docs/README.md` et dans le
   `README.md` racine.

## 2. Interface Web

Les textes de l'interface sont dans `web/i18n/<langue>.json` (objet JSON à
plat : clé → texte), embarqués dans le binaire du serveur. Les gabarits
(`web/templates/*.html`) y accèdent par `tr.<clé>`. La langue est choisie par
le cookie `lang` (route `/lang/{lang}`) ; français par défaut.

### Modifier ou compléter une traduction existante

1. Ajouter la clé dans **`web/i18n/fr.json` et `web/i18n/en.json`** (les deux
   fichiers ont exactement les mêmes clés) ;
2. l'utiliser dans le gabarit : `{{ tr.ma_cle }}` (échappement HTML
   automatique) ;
3. vérifier : `python3 -c "import json;a=json.load(open('web/i18n/fr.json'));b=json.load(open('web/i18n/en.json'));print(set(a)^set(b) or 'ok')"`.

### Ajouter une langue

1. Copier `web/i18n/fr.json` vers `web/i18n/<code>.json` (code court :
   `es`, `de`…) et traduire chaque valeur.
2. Ajouter le code à la liste des langues chargées dans
   `Templates::new()` (`server/src/web.rs`), aujourd'hui `["fr", "en"]` :
   c'est la seule modification de code nécessaire.
3. Adapter le sélecteur de langue de `web/templates/base.html` : il affiche
   aujourd'hui un lien unique vers « l'autre » langue, défini par les clés
   `other_lang_code` et `other_lang` de chaque fichier de traduction ; avec
   plus de deux langues, le remplacer par une liste de liens `/lang/<code>`.
4. Recompiler le serveur (les fichiers sont intégrés au binaire) et vérifier
   chaque page, publique et d'administration.

Les libellés des statuts utilisés par le client en ligne de commande
(« AuxiNux Vérifié », « AuxiNux Compatible », « Non évalué ») sont définis
dans `shared/src/index.rs` (`label_fr`, `label_en`) ; les messages du client
et du constructeur sont en français.
